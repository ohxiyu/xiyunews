背景

背景

硬件钱包是离线保存用户私钥、并要求在交易时进行物理确认的实体设备，因此常被宣传为自托管加密资产最安全的方式。供应链攻击与直接入侵不同：它攻陷厂商的生产或分销流程，使被篡改或被植入的部件通过正规渠道流到终端用户手中。

彭博社于2026年10月18日发布调查报道，称一些以“防黑客”为卖点的加密硬件设备在出厂时就被植入了监控/间谍组件。报道指出，问题源自设备内部，而非外部攻击所致。

硬件钱包的核心卖点在于私钥被隔离在专用设备之内，而内置监控组件直接动摇了受影响产品赖以成立的前提。这一发现使关注点从单纯的软件漏洞转向设备制造与分销环节。

报道将此事定性为供应链与隐私问题，而非协议层面的漏洞利用，目前也没有已确认的用户资金损失。

影响分析

背景

混合推理智能体：在潜空间中思考、通过文本行动的 LLM 智能体

背景

背景

LLM 智能体通常以文本进行推理和交互，往往依赖思维链，这使得推理过程可被检查，但 token 开销较大。此前的 Coconut（连续思维链，arXiv 2412.06769）等研究探索了训练模型在不受限的连续潜空间中推理，而非使用自然语言。HybridAgents 论文称其贡献在于将潜空间推理与文本层面的动作结合，使智能体既保留工具调用能力，也保留一定的透明度。

Together Computer 发布了混合推理智能体（HybridAgents），该架构让模型在连续的潜空间中完成推理，仅在执行动作和调用工具时输出文本。此次发布附带 GitHub 代码仓库、HuggingFace 模型合集，以及 arXiv 论文 2610.18861 中的评测结果。

作者将该方案定位为弥合两条路线：潜空间推理内部效率高，但缺乏原生工具调用能力和推理透明度；文本智能体则能够执行动作并接受检查。这是一种有别于显式思维链的架构思路，而不只是发布一个新的模型权重。

本次开源发布包括 GitHub 上的代码（togethercomputer/HybridAgent）、一个 HuggingFace 模型合集，以及 arXiv HTML 版本中公开的评测章节。在讨论帖中，一位用户报告称，通过 llama.cpp 运行 bartowski 的 8 位量化 14B 版本时，面对一个简单的聊天、网页搜索与摘要请求，模型在约五分钟内反复输出同一段落的不同变体，直至耗尽回合预算；该用户指出 llama.cpp 可能需要更新才能支持该模型。

hackernews · allinonai · 10月19日 04:48 · 社区讨论 · 单一来源

分析与资料

影响分析

潜空间推理针对的是智能体推理的 token 成本，因此如果该路线成立，影响会体现在开源权重智能体部署的推理经济性上，而非直接作用于某一代币或协议。所报告的 llama.cpp 循环问题表明，实际效果取决于运行时与量化支持，目前尚未得到验证。

讨论热度较高但态度偏向质疑。多位评论者援引对不透明的“neuralese”推理的警告，其中一人称其为“最被禁忌的技术”；也有人认为这适合 Qwen 这类推理输出中重复陈述较多的模型，因为这些复述可以留在潜空间中。另有用户实测 14B 模型在 llama.cpp 8 位量化下出现病态循环，引发了对工具链和量化适配的实际担忧。
