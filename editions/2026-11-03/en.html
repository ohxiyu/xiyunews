Background

Background

The flaw was fixed upstream on Oct. 15, 2026, according to NVD, which describes the issue as a case where tcp_v4_syn_recv_sock() transfers ownership of ireq->ireq_opt to the child socket without copying it. AWS noted the bug affects kernel versions 4.4 and later, where a remote unauthenticated party could send crafted IPv4 TCP packets carrying IP options to an affected listener. Ubuntu's tracker shows fixes in progress for 22.04, 24.04, 26.04 and 26.10, while 20.04, 18.04 and 16.04 show only "Vulnerable."

Anthropic said Claude, using an unreleased internal model, wrote a working remote exploit for CVE-2026-98432, a use-after-free in the Linux kernel's IPv4 TCP handshake path rated 9.8 for severity that affects kernel versions from 4.4 onward. The attack was described in an Oct. 27 research post covering five targets — Chrome, Safari, Android, Windows and Linux — and takes under an hour to locate the memory flaw plus about five minutes to execute a command with root access.

Ubuntu's own tracker still lists every release from 16.04 through 26.10 as affected, while Red Hat shipped fixes for RHEL 8, 9 and 10 on Sunday, Nov. 1, including advisory RHSA-2026:93412. The Go Security Team warned that the underlying bug is not specific to MPTCP, the feature Anthropic's demonstrated exploit requires, and recommended upgrading to a patched kernel.

Anthropic wrote that the bug is a race condition where a lost race only fails the handshake without crashing the system, so an attacker can retry indefinitely. Red Hat published a temporary firewall rule that it says "reduces exposure to this vulnerability but cannot fully prevent it," with a full solution still under development; Debian, SUSE, Oracle Linux and Amazon Linux have also shipped fixes for at least some versions.

Astra can read and write weights to improve Qwen

Background

Background

Weight-space learning is an existing research area: ICLR 2025 hosted a workshop aimed at treating neural network weights as a data modality, and prior lines of work include predicting or generating network parameters, with fast-weight programmer ideas dating back to 1991. Qwen is Alibaba Cloud's family of open-weight large language models, first released in 2023. Transformer blocks, the architecture behind these models, stack self-attention with Multi-Layer Perceptron (MLP) layers — the components Astra edited here.

A researcher has published a demonstration of "weight-space programming," in which an LLM called Astra inspects a neural network's weights directly and edits them to change model behavior, without being allowed to write training loops. In the reported examples, Astra traced a small reasoning model's repetitive looping to a direction written by the MLP layers 15 and 19 and subtracted it from 64 output columns in each layer (131,072 weights), and separately edited a small Qwen model's weights to improve its math performance several-fold without retraining.

Commenters on Hacker News described the demonstration as striking evidence that current LLMs may hold some native understanding of their own weight structure rather than requiring external tooling to inspect it. The work is presented as a single-author blog demonstration, not a peer-reviewed or frontier-lab release.

According to the write-up, 85 of the base model's first 96 practice answers ran to the 32,768-token limit before the weight edit. The author frames the approach as using the model's reasoning to work out what each part of the network computes, or should compute, and then changing weights accordingly.
