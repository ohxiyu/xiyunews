# xiyu.news Logo 规范：稀有信使 v3

版本：v3 · 2026-10-01。用户确认 A「稀有信使」方向，保留稀有实验室的独立圆形头部、圆润主体和偏右观察点，以一道新闻留白形成 xiyu.news 的识别细节，不再使用字母 b 轮廓。本文件是规范的唯一维护源，公开媒体目录的同名文件由脚本复制，不独立编辑。

## 1. 几何母版

使用 `512 × 512` 坐标系，左上角为原点，x 向右、y 向下。下列数值是矢量源文件的真实参数，不是效果图测量值；母版为 `brand/mark.svg`。字标沿用 `brand/wordmark-path.svg`，保留 Liberation Sans 字体许可，不引入运行时字体。

| 部件 | 参数 | 约束 |
| --- | --- | --- |
| 头部 | 圆心 (224, 94)，半径 68，直径 136 | 完整正圆，边界 x=156…292、y=26…162，不削平底边。 |
| 主体 | 左上 (96, 186)，宽 320，高 304 | 四个圆角均 R80，右下 (416, 490)，底边水平。 |
| 头身间距 | 186 − 162 = 24 | 保持分离，不能粘连或添加颈部。 |
| 横向排列 | 主体中心 x=256，头部中心 x=224 | 头部向左偏 32，保留非对称构图。 |
| 新闻横槽 | 左上 (140, 340)，宽 124，高 32，R16 | 水平胶囊形，使用透明留白，不是白色贴片。 |
| 观察点 | 圆心 (342, 264)，外半径 36、内半径 12 | 内外圆严格同心，圆心与主体同色，环宽 24。 |

圆角一致是统一几何比例，不是所有部件半径相等。主体 R80、横槽 R16；头部和观察点使用正圆。直线与圆弧必须相切（G1 连续），不宣称连接具备 G2 曲率连续；禁止底部鼓包、波浪、脚部、削平圆形和无依据的局部曲线微调。

头部、主体、横槽和观察点外圆在 `body` 复合路径中表达，透明部分使用 `fill-rule="evenodd"`；`eye` 是圆环，`pupil` 是同心圆。全部应用共用这三条路径，网站内嵌 SVG 与分享 Canvas 也保持一致。不得将效果图裁切或自动描摹成生产图标。

## 2. 配色和单色版本

| 用途 | 色值 |
| --- | --- |
| 浅色模式标志 / App 底色 | `#1D4C96` |
| 观察点圆环 | `#FFCC29` |
| 暖白背景 | `#FAF9F7` |
| 字标 / 黑色单色版 | `#1B1B18` |
| 暗色模式标志 | `#8FB0E6` |
| 暗色字标 / 推荐背景 | `#E8E6E1` / `#111214` |

独立彩色版圆心跟随主体颜色；网站主体和圆心使用 `currentColor`。App / Apple / maskable 版沿用效果稿的蓝底、白色主体、黄色圆环及蓝色圆心，圆心与背景同色以维持观察点对比度。黑白版圆环透明、圆心与主体同色，横槽始终透明；不能用直接去色替代正式单色文件。

只使用纯色，不添加渐变、描边、阴影、材质、嘴部表情或其他装饰。不得拉伸、旋转、重排部件或单独改变圆角。蓝黄配色承担品牌识别，不用于传达行情涨跌。

## 3. 留白、缩放和平台图标

独立标志外围至少保留实际图形高度的 1/8；母版内部留白不等于完整排版保护区，相邻内容应补足保护区。常规标志建议至少 24 px 高；网站沿用现有紧凑页头、页脚尺寸，不为换 Logo 增加信息流高度。

16 / 32 / 48 px favicon 从 SVG 分别直接栅格化，不缩小已有 PNG。小尺寸仅允许经验收的像素对齐修正，不能任意改变几何；当前版本不维护第二套轮廓。需检查头身分离、横槽和观察点，不保证每个细节在所有显示器上同样清晰。

App 图标为 512 方形、底色 R108，母版缩放 0.74、平移 (66.56, 66.56)。Apple 版本用同构图不透明方底，由系统裁切；maskable 版本用不透明方底，缩放 0.6、平移 (102.4, 102.4)，前景全部位于中心半径 204.8 的安全圆内，不能放大填满。PWA `id` 保持 `/`，不因换 Logo 创建新应用身份。

## 4. 导出与版本管理

依次执行 `python3 scripts/build_brand_assets.py`、`node scripts/render_brand_assets.mjs /absolute/path/to/sharp`、`python3 scripts/build_brand_assets.py --package`。SVG 字标已转曲；透明 PNG、单色版、组合字标、社交图、ICO 和平台尺寸均从母版导出。

v3 使用新的 `*-v3.*` URL；媒体页查询版本为 `brand-20261001`，资源包为 `bmtnews-media-kit-v3.zip`。旧 v1 / v2 版本化文件和 ZIP 保持原字节，继续服务旧缓存页面；通用别名指向当前版。以后必须创建新版本，不覆盖旧 URL 并假设缓存自动刷新。

已安装 PWA 的桌面图标刷新由系统与浏览器控制。使用现有网站更新提示，不强制刷新正在阅读的页面，不清空阅读记录或书签，不要求用户卸载应用。
