## 判断与执行方式

若产品只服务现货异动，关闭合约完全可行，采集量会明显减少；但现货价格无法
替代合约价格，合约独有或当前现货不合格的标的将不再产生新行情事件。

当前机器并无明显资源压力，建议保留可选能力，不因资源顾虑删除实现。用户确认
定位只做现货后，将服务器 /etc/fomobtc.env 中 FUTURES_ENABLED=false，保持
MARKET_ENABLED=true / SPOT_ENABLED=true，重启唯一 systemd 进程；核验
/api/health.enabled_markets 仅含 spot，消息统计不再有 futures。

这不影响 OKX/Binance/Hyperliquid 公告，也不删除历史合约记录。网页仍可查看旧记录，
切换“Binance现货”筛选可只看现货。本轮未擅自关闭合约。
