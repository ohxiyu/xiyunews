# 2.2.0

多交易所公告与新交易对监测，网页按“行情异动 + 各交易所公告”两级分类。

- 新增官方公告 API：Bybit、Bitget、KuCoin（5 秒）、HTX、Bithumb（10 秒；Bithumb 经 CDN 缓存，可能晚数分钟）。
- 公告 API 在东京被拦截（403）的 Upbit 韩国站、Gate、MEXC，以及 Bithumb，改为监测公开行情接口的新交易对：Upbit 10 秒、Bithumb 15 秒推送；Gate 60 秒、MEXC 30 秒只记录网页不推送（长尾上币量大）。重启后首轮列表只基线，一次新增超过 50 个视为异常。
- 交易所自带类型辅助分类（活动类只归档）；推送放行中文、英文与韩文原文，交易所列表接口无正文时网页不显示占位。
- 类别规则变化不再被当作内容修订：去重摘要不含类别，兼容旧摘要（任意类别）。
- 网页：一级分类“全部 / 行情异动 / 交易所公告”，公告下 12 个交易所标签；移除来源下拉框。

验证：Python 78 项、Ruff、Mypy、前端检查通过。本地 log-only 连接真实接口：全部新来源 polling，基线 5686 条；Bithumb 公告接口 302 到 feed-api 已改为直连；Bybit 出现一次偶发失败后自动恢复。Telegram 频道方案经对比放弃：OKX/Bybit/KuCoin/Bitget 频道最近 10 条公告最多覆盖 1 条，且晚 17 分钟到 2 小时。
