# 2.4.0

单条行情异动改为“K 线图 + 中英双语 + 市值”的 Telegram 图片消息（参照用户提供的频道样式）。

- 图片：Pillow 绘制（新增依赖 Pillow 11.3.0，锁文件含哈希），突发用 1m×300（约 5 小时），趋势用 15m×96（24 小时）；红绿蜡烛、成交量、右侧价格轴、最新价虚线与标签，时间为 UTC+8。
- 文案：🇨🇳/🇺🇸 两行，🟢 上涨 / 🔴 下跌，[交易对]，突发“过去 N 秒内上涨了 X%”，趋势“持续走强/走弱，过去 N 小时…”，突破追加 24 小时新高/新低。
- 市值：币安公开产品列表的流通量 × 价格，每 10 分钟刷新，超过 1 小时未刷新不显示；缺失时省略市值段。
- 多条同时到期的行情仍合并为一条文字（大盘联动），不逐条发图。K 线或绘图失败时发送同样的文字，不影响推送。
- 部署：新增依赖，release 使用独立虚拟环境，不再链接旧 venv。

验证：Python 87 项、Ruff、Mypy、前端检查通过；本地用真实 ZEC 1m K 线渲染（约 0.3 秒、24KB）。
