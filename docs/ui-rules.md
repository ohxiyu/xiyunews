# 前端与 Telegram

2026-09-16 用户授权两端并行；前端参考 bmt.news 的暖白/深色阅读界面、深蓝强调色、细分隔线、高密度时间线与清晰标题层级。保留 FomoBTC 品牌与真实数据，不复制参考站新闻、评分或统计。

保留实时/历史/状态、类型及来源筛选、搜索、分页、正文展开、官方原文和交付状态；响应式布局与可访问标签。外部正文安全转义，链接仅官方 HTTPS。网页关闭不影响采集和推送。

Telegram 先私聊，配置与验收见[运行手册](telegram-runbook.md)。

最新反馈：去掉“市场动态”大标题和大块介绍；缩小头部、间距与正文预览。左侧显示采集时刻（含日期）和Telegram API推送确认时刻，不用序号；没有确认时间显示—，不能将发布时间或归档时间冒充推送时刻。行情使用notification_sent，公告使用sent。

最新内容要求：公告呈现标题、最多180字的事实摘录、明确关联币种；过滤问候及免责声明。异动只呈现涨跌标题。左侧时刻统一HH:mm。币种仅从明确的标题简称/交易对提取，无法确认显示未识别；不把API/UTC等缩写误作币种。全文通过官方原文访问，不在列表重复铺开。

策略 v2：突发标题使用实际 1/3 分钟窗口；趋势使用实际 6/24 小时窗口并标持续走强/走弱，突破明确标24小时新高/低。网页直接使用后端规范标题，Telegram行情只发送同一句标题。旧历史事件保留原口径，不按新策略重新解释。
