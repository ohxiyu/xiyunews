# 消息呈现规则

本项目无 Web UI；菜单、网页组件及断点布局不适用。若以后新增前端，另开 Issue 定义适配标准。

当前 Telegram 消息由 [alert_manager.py](../src/alert_manager.py) 生成，使用 HTML parse mode：标题、交易对与市场、带正负号的两位小数涨跌幅、方向、24h 成交额、分组；成交额以 M/B 缩写显示。
保持中文短行、每行一个信息点，避免宽表格，手机上能直接辨认现货/合约和方向。不要只靠颜色或表情表达涨跌。修改模板时检查 HTML 转义、长交易对及正负值，真实 Telegram 截图/收件证据需要授权后补充。
消息是行情预警，不加入交易建议或自动下单入口。日志 JSON 契约见 [数据契约](data-contract.md)。
