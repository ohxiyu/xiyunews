# FomoBTC 呈现规则

只读前端在 [web](../web)，实时动态/历史记录/服务状态三个视图。暗色背景、绿色强调、单列事件卡片；700px 以下为顶部导航与两列统计卡片。所有正文用 textContent，原文链接仅允许官方 HTTPS 域名。

时间同时显示发布与发现时间；历史基线、送达未知和降级来源都要可辨认。未配置 API 时显示“待接入后端”，禁止用演示数据冒充实时结果。
行情和公告可筛选搜索，长标题正常换行；分页与实时刷新分离，浏览历史时不得自动打断位置。运行延迟显示测量区间，不能把本机计算耗时当成总推送延迟。
Telegram 消息首屏包含来源、标题、原文链接及事件短 ID。标题先发送，正文截短后再 HTML 转义；保留真实分类/修订状态。无网页管理或交易功能，所有配置仍在服务器端。
