# FomoBTC 呈现规则

只读前端在 [web](../web)，实时动态/历史记录/服务状态三个视图。暗色背景、绿色强调、紧凑时间线（现货预警与公告混排，不冒充全部逐笔成交）；shadcn/ui Button/Input/Badge；顶部单行状态、紧凑筛选，按发现时间倒序，公告标题及正文主体直接展示，列表滚动，手机不展示大统计卡片。正文使用 React 文本转义或 textContent，原文链接仅允许官方 HTTPS 域名。

时间线显示发现时间；历史基线、送达未知和降级来源都要可辨认。未配置 API 时显示“待接入后端”，禁止用演示数据冒充实时结果。
行情和公告可筛选搜索，长标题正常换行；分页与实时刷新分离，浏览历史时不得自动打断位置。运行延迟显示测量区间，不能把本机计算耗时当成总推送延迟。
Telegram 消息首屏包含来源、标题、原文链接及事件短 ID。标题先发送，正文截短后再 HTML 转义；保留真实分类/修订状态。无网页管理或交易功能，所有配置仍在服务器端。

公告主体删除通用一般性公告说明：段首说明只删该段，正文尾部说明从该处截断。行情显示“XX 币约 2–3 分钟内上涨/下跌 X%”，不把分钟桶说成严格180秒。

内容顺序：正文、关联币种/当前美元市值、可选按需TradingView现货图、时间与source页脚。公告标注自动匹配可能不准确。走势图为当前1日视图，不代表报警窗口。
