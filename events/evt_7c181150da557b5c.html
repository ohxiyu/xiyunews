目前结论

  1. #0110.23
    首次出现2026.10.23 15:40 · 报道时间

    【Initia 链疑遭无限铸币攻击，攻击者已套现约 260 万美元】

    安全研究员 spreekaway 指出，Initia 疑似遭遇无限增发漏洞，多个代币被任意增发，攻击者已套现约 260 万美元的 ETH，同时在 Initia 上仍持有约 454 万美元的 iUSD、USDC、AUSD 和 ETH。

    来源依据：foresightnews · theblockbeats

  2. #0210.23
    回应2026.10.23 16:03 · 报道时间

    Initia因安全事件暂停L1主网及Rollup运行

    Initia 因该安全事件暂停了 L1 主网及所有 Rollup 运行，并正与安全团队、验证者及交易所协作评估影响。

    此后状态：Initia 在安全事件后已暂停 L1 主网及所有 Rollup，团队正调查影响范围并提醒用户警惕非官方信息。

    来源依据：theblockbeats

  3. #0310.23
    确认2026.10.23 16:25 · 报道时间

    Initia联创：漏洞攻击涉及MoveVM，原生代币INIT未受影响

    Initia 联合创始人 Zon 表示，漏洞可能源于其基于 Cosmos SDK 的 MoveVM 中的 Day 0 漏洞，该漏洞允许攻击者在 Initia L1 上额外铸造代币，但原生代币 INIT 未受影响；在链暂停前，攻击者已通过增发并跨链转移的方式转出价值约 270 万美元的 AUSD、ETH 和 USDC。

    此后状态：Initia L1 主网及所有 Rollup 仍处于暂停状态；联合创始人称漏洞可能源于 MoveVM Day 0 漏洞，原生代币 INIT 未受影响，团队仍在调查影响及后续细节。

    来源依据：theblockbeats
