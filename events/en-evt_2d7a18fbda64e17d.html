    Telegram Desktop曝高危漏洞：点击恶意链接可一键窃取本地任意文件及会话，建议加密社区用户立即更新

    Security researcher beaksec disclosed a high-severity Telegram Desktop flaw (CVE-2026-107181) in versions 7.2.8 and earlier that lets attackers use crafted tg:// links to read and exfiltrate arbitrary local files — including tdata session files, enabling account takeover — which is patched in 7.2.9, prompting an urgent update call for crypto community users.
