目前结论

Anthropic 的 Claude Code 团队发布博文，介绍其大规模代码审查流程：据其描述每天处理约 3 万个 PR，大部分路径已自动化，人的注意力被引导到高风险改动上。文档、文案、仅内部使用的功能以及带开关的增量改动等低风险改动，只要自动审查与安全检查通过，就不需要人工批准。 按照该团队自己的表述，这套流程的目的是把有限的人工审查精力只放到有风险的地方；同时评估套件（eval suite）会随每一次事故扩充，审查器的每一次改动都要针对整个套件评分。 每天约 3 万个 PR 的数字以及低风险类别（文档、文案、仅内部功能、带开关的增量改动）均出自该团队自己的博文，而非独立测算。
