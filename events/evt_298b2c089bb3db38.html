目前结论

OpenAI 推出 GPT-6.1 Terra，这是一款更便宜、更快的计算机使用模型，在 Agents' Last Exam 专业任务基准测试中与旗舰模型 GPT-6 Astra 表现相当，而 token 价格仅为后者的十分之一，API 价格为每百万输入/输出 token 1 美元/5 美元，并已在 ChatGPT Work、Codex 和 API 上提供。

    OpenAI 推出 GPT-6.1 Terra，半价出售的半好 AI 模型

    新增了GPT-6.1 Terra的定价、可用范围和基准表现：标准API价格较GPT-5.6 Terra低50%，面向Plus、Pro、Enterprise和Edu用户在ChatGPT Work和Codex推出，并公布内部事实错误率及Terminal-Bench 4.0成绩。

    此后状态：OpenAI已发布GPT-6.1 Terra；该中端模型以较GPT-5.6 Terra低50%的标准API价格、改进的computer-use能力和更强的事实性/编码基准表现推出，并向ChatGPT Work、Codex用户及开发者开放。
