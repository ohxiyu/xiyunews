Current outcome

Lido's engineering lead warned that during Ethereum's Glamsterdam hard fork a node operator could front-run delegated staking deposits using 0xB0-prefixed builder withdrawal credentials so the user's validator never appears and the deposit is credited to a builder with the same public key, urging staking protocols to adopt pre-deposit checks.
