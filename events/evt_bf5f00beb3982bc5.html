目前结论

Supabase 宣布收购 Turso，理由是为 AI Agent 提供可即时按需创建的独立数据库；两家产品暂不合并，Turso 数据库继续开源，计划逐步打通（小任务用 Turso，规模变大后迁移到 Supabase 的 Postgres），Turso 创始人 Glauber Costa 将加入 Supabase 负责 Agent 服务，收购金额未公布。
