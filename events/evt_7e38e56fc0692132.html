目前结论

腾讯混元已开源发布 Hy Memory 2.0，包含专用模型 Hy-Memory-30B-A3B、记忆框架和 MemHub 应用；2.0新增工作记忆与代码记忆（含Git回滚代码追溯），让10款AI编程工具共用本地记忆，并在四套记忆系统测试中以55.49平均分略高于 Opus 5 的54.62分。

    腾讯混元发布 Hy Memory 2.0，全面开源专用记忆模型、记忆框架以及可连接 10 款 AI 工具的 MemHub 本地记忆应用，声称在 4 项基准测试中位居开源第一，并报告在腾讯自家产品中准确率大幅提升。

    腾讯Hy Memory 2.0开源：10款AI工具共享记忆，连回滚过的代码都能追溯

    新增披露：Hy Memory 2.0新增工作记忆与代码记忆，可结合Git记录追踪文件和函数修改历史（包括回滚代码追溯）；专用模型为Hy-Memory-30B-A3B（总参数300亿，每次激活约30亿）；四套记忆系统测试平均55.49分，略高于Opus 5的54.62分；MemHub让Cursor、Codex、Claude Code等10款工具共用一份本地记忆。
