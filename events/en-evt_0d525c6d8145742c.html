Current outcome

Together Computer released Hybrid Reasoning Agents (HybridAgents), an agent architecture in which the model performs its reasoning in continuous latent space and emits text only for actions and tool calls. The release ships with a GitHub repository, a HuggingFace model collection, and evaluations in arXiv paper 2610.18861. The authors position the approach as bridging latent reasoning, which is efficient internally but lacks native tool access and reasoning transparency, with text-based agents that can act and be inspected. It is an architectural departure from explicit chain-of-thought rather than a new model checkpoint alone. The open release spans code on GitHub (togethercomputer/HybridAgent), a HuggingFace collection, and a published evaluation section in the arXiv HTML version. In the discussion thread, one user reported that the 14B variant, run through llama.cpp with bartowski's 8-bit quantization, looped on variations of the same paragraph for roughly five minutes until it exhausted its turn budget on a simple chat, web search and summarization request; the user noted llama.cpp may need updates to support the model.
