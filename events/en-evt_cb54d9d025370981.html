Current outcome

Developer momo5502 published a blog post describing an experiment in which AI agents consumed roughly 500 billion tokens to decompile a commercial first-person shooter down to byte-matching assembly. The post, which drew a large Hacker News thread, discusses the cost, the agent architecture used, and whether functional equivalence would have been enough. The post provides a concrete, large-scale datapoint on the cost of agentic LLM workflows, attaching a 500-billion-token figure to a single reverse-engineering project. Commenters read it as evidence that byte-matching decompilation is a deliberately expensive target compared with functional equivalence. Byte-matching (matching) decompilation means writing original C++ that, compiled with the era-correct toolchain, produces byte-for-byte the same machine code as the shipped binary. According to a commenter quoting the post, two earlier posts by the author have since been removed.
