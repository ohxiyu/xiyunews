    Node2Shell 演变为 HTTP2Shell，影响范围波及大量 HTTP 库与应用

    编号为 CVE-2026-111497 的 Brotli 解码器漏洞此前以“Node2Shell”之名传播，如今又以“HTTP2Shell”的名义流传；相关报道称这是一个无需认证即可远程执行代码的漏洞，影响范围覆盖大量 HTTP 库与应用，而不只是 Node.js。Aikido 的文章称，其检测能力可以在代码仓库和容器镜像中标记出受影响的 Node.js 版本。 该漏洞位于 Brotli 解码环节，而这一压缩路径在 HTTP 处理中被广泛使用，因此受影响面并不局限于单一运行时；Vercel 表示其 WAF 已部署规则，用于检测并阻断针对该漏洞的利用尝试。 讨论中有评论者指出，Ubuntu 仍将 libbrotli1 的补丁标注为“审核中”、严重级别为中等，这拖慢了 libcurl 乃至 git 等一系列软件包的更新。也有评论者质疑：据称 2 月就已发布的修复，当时为何未被当作安全问题处理。
