目前结论

Paradigm 合伙人兼首席技术官 Georgios Konstantopoulos 在 X 上表示，团队即将推出一款已完成审计、内置即时编译（JIT）的新 EVM，名为 evm2，代码已在 GitHub 公开。evm2 是一个用 Rust 编写的 EVM 实现，开发者可在不改动核心代码的情况下自定义操作码、Gas 规则、交易类型和预编译合约；其 README 页面称执行速度最高可达当前主流 Rust EVM 实现 revm 的 2 倍。 据 Konstantopoulos 的说法，evm2 未来将应用于 Foundry、Reth、Tempo 以及所有采用其技术栈的 EVM 生态项目，而这三者目前均基于 revm 构建。 审计被描述为已完成，但发布口径是“即将推出”，而非已经上线。2 倍的速度数字来自仓库 README 的表述，并非经独立验证的基准测试结果。
