Current outcome

A critical Linux IPv4 TCP use-after-free, CVE-2026-98432 with CVSS 9.8, left major distributions such as Ubuntu and RHEL without patches at disclosure, though practical exploitation is constrained by packet filtering and multi-core requirements.

  1. #0111.02
    Confirmation20:36 UTC · publication time

    Claude-Built Linux Exploit Targets Bug That Ubuntu Still Hasn't Patched

    Anthropic said Claude, using an unreleased internal model, wrote a working remote exploit for CVE-2026-98432, a use-after-free in the Linux kernel's IPv4 TCP handshake path rated 9.8 for severity that affects kernel versions from 4.4 onward. The attack was described in an Oct. 27 research post covering five targets — Chrome, Safari, Android, Windows and Linux — and takes under an hour to locate the memory flaw plus about five minutes to execute a command with root access. Ubuntu's own tracker still lists every release from 16.04 through 26.10 as affected, while Red Hat shipped fixes for RHEL 8, 9 and 10 on Sunday, Nov. 1, including advisory RHSA-2026:93412. The Go Security Team warned that the underlying bug is not specific to MPTCP, the feature Anthropic's demonstrated exploit requires, and recommended upgrading to a patched kernel. Anthropic wrote that the bug is a race condition where a lost race only fails the handshake without crashing the system, so an attacker can retry indefinitely. Red Hat published a temporary firewall rule that it says "reduces exposure to this vulnerability but cannot fully prevent it," with a full solution still under development; Debian, SUSE, Oracle Linux and Amazon Linux have also shipped fixes for at least some versions.

    Source evidence: Decrypt
