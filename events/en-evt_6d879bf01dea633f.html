Current outcome

GitBook disclosed that a "sophisticated, highly targeted attack using AI agents" gained unauthorized access to some of its infrastructure credentials at 7 p.m. Central European Time on November 2. The documentation platform, widely used by crypto projects, took authentication-gated sites offline, revoked personal API tokens and urged customers to replace connected credentials. GitBook's connections to customer accounts and external services mean the blast radius extends to crypto teams' integration tokens, Git Sync secrets and API tokens. PancakeSwap responded by temporarily taking its documentation offline before moving it off the platform, while saying its own systems were not compromised. GitBook said its investigation found no evidence that hosted content was modified, and that potentially exposed data includes integration tokens, Git Sync secrets, API tokens and questions submitted to its AI assistant. By Tuesday afternoon the company said its application, API and published documentation were accessible again, though some services could remain degraded; it has not explained how the attacker used the AI tools, which AI systems were involved, or how the credentials were obtained.
