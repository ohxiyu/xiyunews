目前结论

Meta 新发布的开放权重模型 Muse Spark Open 在 Artificial Analysis 智能指数上得分 39，取代英伟达的 Nemotron 3.5 Super VL 成为美国最强开放模型，但落后于小米 MiMo-V2.6-Pro（46）和智谱 GLM-5.3（45）等中国模型，其智能体测试表现明显偏弱，但以同类最佳的知识准确性和更低的 token 成本弥补。

  1. #0110.15
    首次出现2026.10.15 17:47 · 报道时间

    欢迎 Muse Spark Open：Meta 推出的开放权重前沿多模态混合专家模型

    Meta 发布了 Muse Spark Open，这是一个开放权重的前沿多模态混合专家模型，Meta 称其为“迄今为止美国最强的开放权重模型”。Meta 表示，这是同类模型中首个可在桌面端运行的产品，需使用两台 Apple M5 Ultra Mac Studio 和最新的 MLX 框架；Hugging Face 上的模型页面将其列为 Muse-Spark-Open-816B-A42B。 由于权重公开发布，前沿级多模态参数可以被下载、微调和自行部署，而不再只能通过 Meta 的服务访问。Meta 同时把 Apple 芯片定位为目标部署平台，主张这一级别的模型已可在本地桌面端运行。 Meta 与 Apple 为此次发布进行了合作，模型针对在 Apple 芯片上本地运行做了优化；社区引用的 Meta 部署文档显示其支持多种模型运行器，包括 Unsloth 和 MLX。已公布的模型标识为 Muse-Spark-Open-816B-A42B。

    来源依据：bigwheels · Hugging Face Blog · The Verge AI · TechCrunch AI

  2. #0210.16
    确认2026.10.16 00:54 · 报道时间

    Meta与苹果罕见联手：8160亿参数Muse Spark开源，两台Mac Studio就能本地运行

    新增细节：模型支持 100 万 Token 上下文；四台 M5 Ultra Mac Studio 协同运行在 8192 Token 上下文下约 37 tokens/秒；采用自定义 Muse Model License，允许修改、商用和分发但需注明来源，企业连续12个月营收超过2000万美元若将模型作为 API 服务对外提供需与 Meta 另行签约；4 位精度下仍需约 493GB 内存，最低部署需两台配备 512GB 统一内存的 M5 Ultra Mac Studio，硬件成本超过 4 万美元。

    此后状态：Meta 的 Muse Spark Open 已在 Hugging Face 上发布，并针对 Apple 芯片优化，可在本地 Mac Studio 上运行。后续报道补充了 100 万 Token 上下文、约 37 tokens/秒速度、自定义 Muse Model License 的营收门槛与 API 服务条款等细节。

    来源依据：theblockbeats
