Current outcome

The b14g vulnerability led to the unauthorized extraction of about 97 million staked CORE; b14g paused affected contracts. Core DAO says Core network security is unaffected and is coordinating with b14g and exchanges to trace and freeze funds, with most stolen CORE still on the Core chain.

    Response04:08 UTC · publication time

    【Core DAO：b14g 漏洞不影响 Core 网络安全】

    Core DAO responded to the b14g vulnerability, saying it does not affect Core network security; Core consensus, validators and staking contracts operated normally, and CORE staked directly or through other protocols was unaffected. It is coordinating with b14g and exchanges to trace and freeze attacker funds, with most stolen CORE still on the Core chain.

  2. #0211.01
    Initial02:35 UTC · publication time

    【b14g 遭未经授权提取 9700 万枚 CORE，已暂停合约并冻结部分资金】

    b14g, a Bitcoin dual-staking layer, reported that about 97 million staked CORE tokens were extracted without authorization, prompting it to pause the affected contracts and work with Core, security partners and exchanges to freeze and recover funds, with roughly 9 million CORE frozen and 68 million still on the Core chain.

    Source evidence: foresightnews
