Current outcome

Binance removed all API keys linked to third-party options trading platform SignalPlus after SignalPlus reported a potential security issue, saying its own systems and user funds were unaffected.

Progress timeline

  1. #0111.05
    Response11:02 UTC · publication time

    Binance, Deribit revoke SignalPlus API keys after security issue

    Deribit also proactively revoked SignalPlus-linked API keys, saying it found no indication of impact on its systems or data; both exchanges advised users to review positions and open orders and wait for SignalPlus to confirm remediation before reconnecting.

    State after update: After SignalPlus reported a potential security issue, both Binance and Deribit proactively revoked SignalPlus-linked API keys; both said their systems and user funds were unaffected and advised users to wait for SignalPlus to confirm remediation before reconnecting.

    Binance proactively deleted all API keys associated with third-party options platform SignalPlus after SignalPlus reported a potential security issue, stating its own systems and user funds were unaffected and advising users to re-bind keys only once the problem is fully resolved, with IP whitelisting enabled.
