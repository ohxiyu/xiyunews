Current outcome

Binance and Deribit have revoked SignalPlus-linked API keys; SignalPlus disclosed the intrusion was carried out via a fake Microsoft Teams invite, reported losses under $82,000 and has begun full reimbursement, with services temporarily suspended and expected to resume within days after security review and patching.

Progress timeline

3 material updates
  1. #0111.05
    Escalation19:02 UTC · publication time

    Binance, Deribit revoke SignalPlus API keys after fake Teams invite attack

    The new report adds the cause and scope of the SignalPlus security incident: attackers used a compromised Telegram contact to send a fake Microsoft Teams meeting invite, compromised an engineer’s computer and reached the internal network; SignalPlus said losses were under $82,000, has begun full reimbursement, suspended services for security review and patching, and expects restoration within days; Deribit customers’ trading, monitoring and automation through SignalPlus stopped working.

    State after update: Binance and Deribit have revoked SignalPlus-linked API keys; SignalPlus disclosed the intrusion was carried out via a fake Microsoft Teams invite, reported losses under $82,000 and has begun full reimbursement, with services temporarily suspended and expected to resume within days after security review and patching.

    Source evidence: Cointelegraph

  2. #0211.05
    Response11:02 UTC · publication time

    Binance, Deribit revoke SignalPlus API keys after security issue

    Deribit also proactively revoked SignalPlus-linked API keys, saying it found no indication of impact on its systems or data; both exchanges advised users to review positions and open orders and wait for SignalPlus to confirm remediation before reconnecting.

    State after update: After SignalPlus reported a potential security issue, both Binance and Deribit proactively revoked SignalPlus-linked API keys; both said their systems and user funds were unaffected and advised users to wait for SignalPlus to confirm remediation before reconnecting.

    Source evidence: wublockchainenglish · foresightnews

  3. #0311.05
    Initial10:53 UTC · publication time

    【币安：已删除所有与 SignalPlus 关联的 API 密钥，作为一项紧急预防措施】

    Binance proactively deleted all API keys associated with third-party options platform SignalPlus after SignalPlus reported a potential security issue, stating its own systems and user funds were unaffected and advising users to re-bind keys only once the problem is fully resolved, with IP whitelisting enabled.

    Source evidence: foresightnews · Decrypt
