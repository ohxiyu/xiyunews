目前结论

《纽约时报》联合《纽约每日新闻》《芝加哥论坛报》等多家出版机构对隐私浏览器公司 Brave 提起诉讼，指控其抓取受版权保护的内容并违规分发给 AI 客户。诉状于周一提交，点名 Anthropic、Perplexity、Mistral、xAI 和 Cohere 为内容接收方，同时质疑 Brave 的“付费墙拦截器”功能，称其让用户绕过出版商的付费墙。 这些诉讼瞄准的是 AI 搜索的供给层——即把出版商新闻内容输送给模型开发者的索引与 API，而非某一次模型训练，这使 Brave 的商业搜索 API 及其绕过付费墙的功能直接面临法律质疑。 诉状引用 Brave 2023 年的一份指南，其中将 API 最常见的用途描述为对大语言模型进行“训练与接地（grounding）”；而 Brave 现行 API 条款（2026 年 9 月 1 日更新）禁止客户缓存、转售结果，或用其训练和改进 AI 模型。截至起诉之时，这些都还只是诉状中的指控，法院尚未作出任何裁决。
