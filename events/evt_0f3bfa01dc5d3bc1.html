    Cloudflare 的封闭测试针对其代币化 Monetization Gateway，网站可通过 HTTP 402 按请求、查询或 Token 向 AI Agent 收费，并使用 USDC 在 Base 区块链上结算，应用场景包括 AI 推理、网页搜索、市场信号及 PDF 生成。
