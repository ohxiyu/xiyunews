Current outcome

Security researchers at Parameter disclosed a ChatGPT account-takeover chain that abused the product's Preview content and layered frontend defenses. OpenAI confirmed that both frontends rejected the reported messages, resolved the issue on October 26 as a P1-severity bug, and awarded a total bounty of $5,000. A confirmed account-takeover path in ChatGPT means a single clicked share link could run code inside a victim's authenticated session, exposing conversation lists and private content. The chain required user interaction and no in-the-wild exploitation has been reported. According to the researchers' account, the Preview sandbox itself held — code rendered there could not read the main page — and the bypass instead worked through other layers such as postMessage, CSP and JSONP gadgets. The disclosed chain depended on the victim clicking a public share link.
