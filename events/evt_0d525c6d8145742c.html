目前结论

Together Computer 发布了混合推理智能体（HybridAgents），该架构让模型在连续的潜空间中完成推理，仅在执行动作和调用工具时输出文本。此次发布附带 GitHub 代码仓库、HuggingFace 模型合集，以及 arXiv 论文 2610.18861 中的评测结果。 作者将该方案定位为弥合两条路线：潜空间推理内部效率高，但缺乏原生工具调用能力和推理透明度；文本智能体则能够执行动作并接受检查。这是一种有别于显式思维链的架构思路，而不只是发布一个新的模型权重。 本次开源发布包括 GitHub 上的代码（togethercomputer/HybridAgent）、一个 HuggingFace 模型合集，以及 arXiv HTML 版本中公开的评测章节。在讨论帖中，一位用户报告称，通过 llama.cpp 运行 bartowski 的 8 位量化 14B 版本时，面对一个简单的聊天、网页搜索与摘要请求，模型在约五分钟内反复输出同一段落的不同变体，直至耗尽回合预算；该用户指出 llama.cpp 可能需要更新才能支持该模型。
