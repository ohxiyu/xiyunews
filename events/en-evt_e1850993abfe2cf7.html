Current outcome

Alpine Linux disclosed an attempted exploitation of CVE-2026-97229, an integer-overflow remote code execution flaw in Ruby's regular expression engine that GitLab only patches in its own packages, leaving source-built images on version 19.3.6 vulnerable until the image was rebuilt with Ruby 3.3.13 on October 27.
