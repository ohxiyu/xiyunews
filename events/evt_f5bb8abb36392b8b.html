目前结论

Anthropic donated its Agent Skills format — the SKILL.md-based 'work manual' standard already used by ChatGPT, Cursor and GitHub Copilot among 70+ platforms — to the Linux Foundation's Agentic AI Foundation, transferring the name, logo, GitHub organization and domain to joint multi-company maintenance alongside MCP, while proposing versioning, a formal proposal process and security guidance amid reports of malicious skills in the ecosystem.
