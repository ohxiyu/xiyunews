目前结论

Cloudflare 已聘用整个 Deno 团队，Deno 运行时进入为期一年的仅错误修复和安全更新阶段后停止官方开发；Deno Deploy 将在6个月后关闭，客户迁至 Cloudflare Workers；JSR 继续运营并迁移基础设施至 Cloudflare；Ryan Dahl 和 Bert Belder 负责将 celld 整合进 workerd。

    Node.js之父加入老对手Cloudflare，Deno运行时一年后官方停更

    Deno Deploy 将于6个月后关闭，付费客户迁至 Cloudflare Workers；JSR 继续运营并将基础设施迁至 Cloudflare；Ryan Dahl 与 Bert Belder 将把 celld 的分布式 Workers/Durable Objects 能力整合进 workerd。

    此后状态：Cloudflare 已聘用整个 Deno 团队，Deno 运行时进入为期一年的仅错误修复和安全更新阶段后停止官方开发；Deno Deploy 将在6个月后关闭，客户迁至 Cloudflare Workers；JSR 继续运营并迁移基础设施至 Cloudflare；Ryan Dahl 和 Bert Belder 负责将 celld 整合进 workerd。

  2. #0210.09
    首次出现13:03 UTC · 报道时间

    Deno将加入Cloudflare

    Cloudflare正在收购Deno，Deno自身的运行时开发将逐步收尾，先进行为期一年的每月漏洞修复和安全更新，随后结束，项目将保持开源，但不再由其原团队提供支持。
