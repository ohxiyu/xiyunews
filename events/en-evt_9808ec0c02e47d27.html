Current outcome

Anthropic has migrated its main code repository off Git to Scion, its purpose-built server-side version control system. Scion supports over 30,000 daily merges and about 25 million CI checkouts, with much lower resource usage than the prior Git mirror architecture, and is accompanied by the Antique code review tool. Scion is not open-sourced and is aimed at very large repositories with many parallel coding agents.
