Current outcome

The Ethereum Foundation and the Open Anonymity Project launched zkAPI on Ethereum mainnet, a zero-knowledge payment system that decouples payment from identity so users can pay for AI API inference (and other metered services) anonymously through time-limited, quota-capped API keys settled against on-chain vault deposits.
