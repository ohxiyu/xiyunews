Current outcome

Arbitrum paused new Stylus activations on Arbitrum One and Nova on October 2 via Security Council emergency action, citing rising risks from AI-assisted attacks via hand-crafted WebAssembly. Existing Stylus programs keep running and can be renewed; ordinary Solidity contracts unaffected. Pause implemented by raising activation gas to prohibitively expensive level, no ArbOS upgrade. No attack enabling theft of user funds discovered. BoLD one-step proof guard can delay unconfirmed withdrawals if conflicting proofs accepted, but pause of settlement depends on condition. No date for restoring activations.
