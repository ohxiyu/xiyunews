Current outcome

Anthropic's Claude Code now supports MCP Tasks and Elicitations, enabling plugins to manage long-running asynchronous tasks, keep them running on remote servers after the session closes, and prompt users mid-task via forms, in public beta via CLI 2.1.304+ with adapter support required.
