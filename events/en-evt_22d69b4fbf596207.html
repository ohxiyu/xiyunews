    Mistral Large 4发布：1.05万亿参数，自称做出欧美最强开源模型

    Added release details: Mistral Large 4 is a 1.05T-parameter MoE model activating 49B parameters per inference, natively supports image-text input, has up to 1M-token context; API preview is available, open weights are planned for October 27, and self-reported benchmark scores were provided.

    State after update: Mistral has released flagship model Mistral Large 4 (internally nicknamed Le Chonk), an MoE model with 1.05T total parameters and 49B active parameters, multimodal support and 1M-token context; API preview is available, open weights are planned for October 27, and Mistral claims it is the strongest open-weights model from the US or Europe with self-reported benchmarks.
