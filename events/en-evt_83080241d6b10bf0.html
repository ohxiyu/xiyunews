Current outcome

Polkadot Community Foundation warned that Fearless Wallet's browser extension (versions 3.0.1–3.0.5) contains malicious code that sends users' private keys to attacker-controlled servers, urging all users since February 2025 to generate new keys and move assets immediately, with 17,286 DOT already reported stolen across eight users.
