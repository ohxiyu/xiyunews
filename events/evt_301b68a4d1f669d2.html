目前结论

SlowMist 报告称，LiteLLM 再次遭遇供应链攻击：PyPI 上的恶意版本 1.107.0 及其 Docker 镜像会在 Python 启动时自动执行，窃取云凭证、AI API 密钥和 SSH 私钥，并实现远程代码执行；建议用户避免使用 1.107.0，从干净镜像重建，轮换凭证并锁定 1.106.2。

进展时间线

3 次实质进展
  1. #0110.21
    首次出现2026.10.21 14:00 · 报道时间

    PyPI 上被篡改的 LiteLLM 1.107.0 安装凭据窃取器和后门

    PyPI 上被篡改的 LiteLLM 1.107.0 版本携带了凭据窃取器和后门，促使维护者告知用户锁定到 1.106.2 或更早版本，同时向企业客户分发禁运中的修复程序。

    来源依据：abhisek

  2. #0210.21
    修复2026.10.21 15:28 · 报道时间

    LiteLLM今年第二次遭投毒：不调用也能偷密钥

    JFrog 披露该供应链攻击还影响官方 Docker 镜像，PyPI 全部七个平台安装包均被植入木马；PyPI 已移除恶意版本，Docker Hub 已撤下受影响镜像；攻击者使用的发布源码指向名称仅差一个连字符的仿冒仓库；建议将凭证视为可能泄露、隔离并重建环境、轮换密钥，回退到 1.106.2。

    此后状态：LiteLLM 1.107.0 的恶意 PyPI 包和受影响 Docker 镜像已被下架；JFrog 建议受影响用户轮换凭证并重建环境，已确认安全回退版本为 1.106.2，但恶意代码如何混入发布流程仍未查清。

    来源依据：theblockbeats
