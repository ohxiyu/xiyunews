Current outcome

Microsoft CEO Satya Nadella published a framework calling for enterprises to treat AI models as internal security risks — separating the model from the agent execution harness, enforcing external control over data and tool access, keeping tamper-proof audit logs, and installing a human emergency stop for agents — backed by Microsoft's MXC isolation tool now generally available on Windows.
