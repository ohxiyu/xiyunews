Current outcome

Tencent Hunyuan has open-sourced Hy Memory 2.0, including the dedicated Hy-Memory-30B-A3B model, memory framework, and MemHub app; version 2.0 adds work and Git-linked code memory (including rollback tracing), lets 10 AI coding tools share a local memory store, and scored 55.49 average versus Opus 5's 54.62 on four memory benchmarks.
