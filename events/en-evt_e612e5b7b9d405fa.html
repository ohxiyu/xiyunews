    分析师：Bloom Trading攻击者正进行大规模洗钱操作

    On-chain analyst Specter reported that the Bloom Trading attacker is conducting automated large-scale money laundering, using 2,152 distinct routes and destination addresses (1,326 Solana, 822 EVM, 5 Zcash), and has bridged 26.099 ZEC into Zcash's Sapling shielded pool.

    State after update: The Bloom compromise remains under monitoring; the company attributed the attack to a remote code execution vulnerability in a third-party module, pledged full reimbursement to nine affected traders, and said private keys were not compromised.   2. #0210.27
    Response09:07 UTC · publication time

    Bloom bot hackers loot $953K faster than you can microwave popcorn

    The report adds key details to the same Bloom compromise: the attack drained about $953,000 in 94 seconds via a remote code execution vulnerability in a third-party module, affecting 48 wallets belonging to nine traders; Bloom pledged full reimbursement to all affected traders and said no private keys were accessed or compromised.

    State after update: The Bloom compromise remains under monitoring; the company attributed the attack to a remote code execution vulnerability in a third-party module, pledged full reimbursement to nine affected traders, and said private keys were not compromised. The earlier investigation and temporary service restrictions are not reported as restored.

    Source evidence: Cointelegraph

  3. #0310.26
    Initial04:33 UTC · publication time

    Blooming cross-chain trading automation tool Bloom Trading suffered a batch wallet compromise in which about $954,000 in SOL (9,408 SOL across 49 victims, largest single loss 1,636 SOL) was moved to suspected attacker addresses, prompting the team to open an investigation and temporarily disable some services.
