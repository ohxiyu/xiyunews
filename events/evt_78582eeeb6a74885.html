目前结论

币安和Deribit已撤销与SignalPlus关联的API密钥；SignalPlus披露此次入侵通过伪造Microsoft Teams邀请实施，损失低于8.2万美元并已开始全额赔付，服务暂时中止，预计完成安全审查和修补后数日内恢复。

进展时间线

3 次实质进展
  1. #0111.05
    升级19:02 UTC · 报道时间

    虚假Teams邀请攻击后，Binance、Deribit撤销SignalPlus API密钥

    新报道补充了SignalPlus安全事件的原因和影响范围：攻击者通过被入侵的Telegram联系人发送伪造Microsoft Teams会议邀请，入侵一名工程师电脑并进入内部网络；SignalPlus称损失低于8.2万美元、已开始全额赔付，并暂停服务以进行安全审查和修补，预计数日内恢复；Deribit客户通过SignalPlus进行的交易、监控和自动化已停止工作。

    此后状态：币安和Deribit已撤销与SignalPlus关联的API密钥；SignalPlus披露此次入侵通过伪造Microsoft Teams邀请实施，损失低于8.2万美元并已开始全额赔付，服务暂时中止，预计完成安全审查和修补后数日内恢复。

    来源依据：Cointelegraph

  2. #0211.05
    回应11:02 UTC · 报道时间

    币安、Deribit在安全问题后撤销SignalPlus API密钥

    Deribit 也已预防性撤销与 SignalPlus 关联的 API 密钥，并称未发现其系统或数据受到影响；两家交易所均建议用户检查持仓和未成交订单，等待 SignalPlus 确认问题解决后再重新连接。

    此后状态：因 SignalPlus 报告潜在安全问题，币安和 Deribit 均已预防性撤销与其关联的 API 密钥；两家交易所称自身系统与用户资金未受影响，用户被建议在 SignalPlus 确认问题解决前暂缓重新连接。

    来源依据：wublockchainenglish · foresightnews

  3. #0311.05
    首次出现10:53 UTC · 报道时间

    【币安：已删除所有与 SignalPlus 关联的 API 密钥，作为一项紧急预防措施】

    在SignalPlus报告潜在安全问题后，币安主动删除了与该第三方期权平台关联的所有API密钥，称自身系统及用户资金未受影响，并建议用户在问题完全解决后再重新绑定密钥，同时启用IP白名单。

    来源依据：foresightnews · Decrypt
