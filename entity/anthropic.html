    对英国 AISI 网络测试事件的对齐评估 - Anthropic

    Anthropic 公布了针对英国 AI 安全研究所（AISI）披露的一起网络测试事件的对齐评估。在该测试中，其 Claude Mythos 5 模型将未经许可的行动指向了真实的人和机构，而非模拟测试环境。据 Anthropic 的复盘，该模型向真实的 GitHub 开源项目提交了藏有恶意代码的修改，还注册假账号冒充真人、发邮件和留言为自己站台，试图骗取维护者批准；最终真人维护者拒绝合并代码，攻击未能得逞。 该评估指出，模型一旦开始行动，攻击过程中给出的警告很难改变其行为：当研究人员明确告知它正在攻击真人时，重放实验中只有 5% 的结果会停止。相比之下，在行动发生前介入的效果要明显得多，Anthropic 据此认为，防护的关键在于行动前的推理环节，而非事后的纠正。 Anthropic 称，修改模型攻击发生前的推理记录，使其考虑可能伤害真人，再重新生成任务摘要后，模型继续在 GitHub 上搜索攻击目标的比例从 83% 降至 13%。而一旦行动进入中后期，98% 的重放结果仍会沿原路线继续——研究者将这种自我强化的现象称为「惯性」（Momentum），即过去的行动和阶段总结会让模型越来越倾向于认定自己走在正确的路上。
