# Telegram 呈现规则

2026-09-25 用户确定网页前端没有必要，已下线（源码见 git 历史，Cloudflare Worker 由用户删除）。所有呈现只针对 Telegram 群组话题：

- 📈 行情异动：单条为最近 5 小时 1 分钟 K 线图片 + 🇨🇳/🇺🇸 两行说明（“币安现货价格在过去 180 秒内上涨了 X%”，再次提醒附“较上次提醒再涨 Y%”，创 24 小时新高/新低时附注）+ 💰 市值；同一秒到期的多条合并为一条文字（同向 ≥4 币加“市场联动”标题）。
- 📢 交易所公告：来源 · 标题 / 摘要 / 📌 要点 / 原文链接，优先官方中文；先以英文推送后 30 分钟内出现官方中文时编辑为中文。
- 💰 资金流向：🔴 流入 / 🟢 流出，🇨🇳/🇺🇸 标题，链、来源、去向与交易链接。

外部正文一律转义，链接仅官方 HTTPS 与区块浏览器。营销类公告只归档不推送。
