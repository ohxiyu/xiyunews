# 2.0.0

FomoBTC replaces the CoinSignal runtime with event-driven Binance aggregate trades,
independent Binance/OKX/Hyperliquid announcement collectors, a persistent SQLite
outbox and a read-only dashboard. The original minute-bar reference and thresholds
are preserved; evaluation now occurs on trade events. Historical modules remain
for regression tests, but run.py starts src/platform/app.py.

API confirmation is not device receipt. Ambiguous deliveries are retained as
unknown without automatic replay. Binance announcement credentials are required;
Hyperliquid public preview is an explicit degraded fallback, not a realtime feed.
Optional authorized Telegram client supports live messages and edits.

Local verification and deployment progress: [platform evidence](fomobtc-platform.md).
Migration and rollback: [deployment](../deployment.md).
