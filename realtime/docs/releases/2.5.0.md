# 2.5.0

链上资金流向并入 FomoBTC（移植自 ohxiyu/cex.top），Telegram 改为一个开启话题的群组：📈 行情异动 / 📢 交易所公告 / 💰 资金流向。

## 资金流向
- 地址簿 config/exchange_addresses.json：cex.top seed.sql 的 168 个币安地址（PoR 2026-09-01 热/冷钱包、Ceffu 托管、浏览器标签）；TRON 为 Base58，其余小写。Solana 11 个地址保留但暂不扫描。
- 链：Ethereum（代币 + 原生 ETH，完整区块 3 个一批，原生转账需回执成功）、BNB Chain、Arbitrum、Base（代币）、TRON（USDT，经 TronGrid 以太坊兼容 JSON-RPC eth_getLogs，地址 Base58↔hex 互转）。
- 按地址簿在服务端过滤 Transfer 日志（发送方、接收方各一次）；外部→币安为流入，币安→外部为流出，币安↔币安为内部不报。稳定币按 $1，ETH/BNB/BTC 用币安现货价（60 秒缓存）；门槛 flows.threshold_usd 默认 1000 万美元。
- 每链检查点（meta flow_checkpoint:<链>）首次启动从安全块高前少量区块开始并先持久化；只在整段扫描成功后前进，RPC/价格/回执失败保留检查点 30 秒后重试，落后时按 max_range 连续追赶，不跳块。
- 事件 kind=flow、category=inflow/outflow，中英文标题与摘要（链、来源、去向）直接写入 announcement_i18n；网页“资金流向”分类，Telegram 双语消息（🔴 流入 / 🟢 流出 + 交易链接）。
- 与 cex.top 的差异：常驻进程无 Cloudflare 免费额度限制；BSC/Base/Arbitrum 不扫原生币完整区块（BSC 每分钟约 133 块、每块约 120KB，成本过高），以包装币/稳定币覆盖；TRON 改用日志过滤而非逐钱包 REST（后者在东京无 Key 时 429）。

## Telegram 话题
- TELEGRAM_TOPIC_MARKET / ANNOUNCEMENT / FLOW 为群组话题 ID；sendMessage/sendPhoto 按事件类型带 message_thread_id；发送节奏仍按群（同群每分钟约 20 条上限）。
- scripts/setup_telegram_topics.sh：找到群组、核验已开启话题且机器人有管理话题权限，创建三个话题并逐个发送测试消息，确认后备份并写入配置、清空 TELEGRAM_ANNOUNCEMENT_CHAT_ID、重启；失败自动恢复。

验证：Python 91 项、Ruff、Mypy、前端检查通过。本地真实链上试跑：Arbitrum 扫出一笔 800 万美元 USDC 流出，TRON 日志地址匹配正确，以太坊主备节点均通过 3 块批量；东京实测 ETH/BSC/Base/Arbitrum 官方节点与 TRON JSON-RPC 可用，Solana 公共节点 403/429。
