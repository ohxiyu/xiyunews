# 2.3.0

公告改为“标题 + 摘要 + 要点”，网页中英切换（默认中文），只用交易所官方版本，不做机器翻译。移除 HTX、KuCoin。

- 语言版本（announcement_i18n，每条公告每种语言一行，标注 official/original）：Binance 与 OKX 抓取官方中英文正文；Bybit（中文为官方繁体 zh-TW，原样显示）、Bitget 同时轮询中英文列表并按文章 ID 对应；Bithumb 只有韩文，Hyperliquid 只有英文，新交易对中英文由程序生成。
- 摘要/要点为官方原文句子抽取：摘要取开头两句，要点取之后含时间、交易对或数值的句子；去除问候语与免责声明。无正文（Bitget、多数 Bybit）只有标题。
- Telegram 公告格式：来源 · 标题 / 摘要 / 📌 要点 / 原文链接；优先中文。先以英文推送后 30 分钟内出现官方中文时，用 editMessageText 改为中文（每条最多一次）。详情页暂不可用时重试最多 3 分钟后发送原文。
- 网页：卡片显示当前语言标题、另一语言标题、摘要（可展开）与要点；缺少所选语言时显示原文并标注；行情异动英文由信号数据生成；中英选择仅保存在本机。
- HTX、KuCoin 停止采集，历史记录保留但不再列出。抓取正文不保存 cookie（OKX 会按上次语言跳转）。

验证：Python 83 项、Ruff、Mypy、前端检查通过；本地用真实 Bybit/Bitget/Bithumb/OKX 与生成的交易对构建演示库，中英文界面与 Telegram 样例核验。
