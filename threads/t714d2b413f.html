    Claude Code 团队如何做代码审查

    Anthropic 的 Claude Code 团队发布博文，介绍其大规模代码审查流程：据其描述每天处理约 3 万个 PR，大部分路径已自动化，人的注意力被引导到高风险改动上。文档、文案、仅内部使用的功能以及带开关的增量改动等低风险改动，只要自动审查与安全检查通过，就不需要人工批准。 按照该团队自己的表述，这套流程的目的是把有限的人工审查精力只放到有风险的地方；同时评估套件（eval suite）会随每一次事故扩充，审查器的每一次改动都要针对整个套件评分。 每天约 3 万个 PR 的数字以及低风险类别（文档、文案、仅内部功能、带开关的增量改动）均出自该团队自己的博文，而非独立测算。

    Claude 前沿学院：投入 1 亿美元培养 1 万名工程师

    Anthropic 宣布推出 Claude 前沿学院（Claude Frontier Academy），承诺投入 1 亿美元，到 2027 年底培养 1 万名“前沿部署工程师”（Frontier Deployed Engineer）。该项目被描述为一种驻留式培养计划而非普通课程，由各机构提名其最优秀的工程师参与，围绕 Claude 进行实操训练。 该项目把 Anthropic 的 Claude 生态与大规模企业工程团队直接挂钩，其公开目标是让参与者的能力达到 Anthropic 自家部署工程师的水平。 根据项目说明，参与机构需提名工程师，并在其所在组织内部构建真实的 Claude 项目；有介绍称该计划包含为期数天的线下环节，随后是 12 周的项目实践期。
