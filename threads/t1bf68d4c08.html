    BTCPay Server：攻击面指向2.4.1及更早版本，最新版暂无可信热钱包被盗报告

    11 月 2 日，BTCPay Server 表示其事件响应调查已识别出攻击面，主要针对运行 2.4.1 版本（发布于 2026 年 7 月 23 日）及更早版本的实例。官方称目前暂无运行最新 2.4.7 版本用户热钱包被盗的可信报告，并再次敦促所有运营方及时升级。 BTCPay Server 是由商户自行部署的自托管支付基础设施，因此风险集中在尚未升级到 2.4.1 以上版本的运营方。BTCPay 尚未披露受影响的运营方数量或被盗资金规模。 BTCPay 要求受影响用户向其安全团队提交信息和日志，但尚未公布攻击者如何访问钱包的技术细节。Cointelegraph 称其联系 BTCPay Server 寻求置评，但在发稿前未获回应。

    BTCPay Server 在热钱包被扫空报告后敦促用户关闭实例

    开源自托管的比特币支付处理器 BTCPay Server 在出现其相关热钱包被“扫空”的报告后，建议运营者关闭自己的实例，表明这是一起正在发生的、影响比特币商户的安全事件。该项目的指引还要求运营者升级至 2.4.2 版本，该版本会一并更新 LND 并重新生成其 admin macaroon。 自行运行 BTCPay 实例的商户掌握着服务器所控制资金的私钥，因此在资金被持续盗取的情况下，在关闭或升级之前他们将直接面临损失风险。BTCPay 是托管式支付处理器之外被广泛采用的自托管方案，这使得该警告涉及的运营范围异常广泛。 该事件似乎与 2.4.2 之前版本中的一个闪电网络凭证漏洞有关，攻击者可借此获取控制商店闪电网络资金的凭证。该项目表示，若运营者不确定升级是否已正确生效，应通过用户界面或 btcpay-update.sh 重新执行更新；目前报道中尚未厘清具体损失规模与根本原因。
