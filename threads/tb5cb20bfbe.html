    Block 新语音模型听起来逼真得令人不安

    杰克·多尔西（Jack Dorsey）旗下的 Block 公司从其研究实验室发布了一款新语音模型，称其可在 MacBook M4 Max 上本地运行。这款名为 Dessa 的模型据称能生成笑声、停顿、哭声等类人表达，且无需云端推理。 Block 将本地运行作为该模型的核心特征，指向在消费级硬件上生成音频、而非依赖云端推理。公司在公布时并未披露基准测试结果、许可条款、参数规模或发布时间。 据 Block 介绍，Dessa 是一个仅用语音数据训练的“全双工”语音模型，而非依赖“转写文本＋音频”配对数据训练。已公开的材料以演示样本为主；第三方报道指出，基准测试与访问方式仍未披露。

    Dessa：迄今最逼真的全双工语音模型

    Block 发布 Dessa，一款可同时聆听与说话的全双工语音模型，并称其为迄今最逼真的同类模型。该公司表示，Dessa 可在 MacBook Pro M4 Max 或更高配置的设备上本地运行，并且仅用一台 NVIDIA GB200 NVL72 完成训练。 如果这些说法成立，把自然的打断处理与低时延和消费级笔记本上的本地推理结合起来，将是语音 AI 在部署层面的一次重要进展，使实时语音智能体不再依赖云端基础设施。不过该发布属于厂商公告，尚未有第三方基准测试支撑。 Block 将该模型描述为兼具高表现力与低时延，并强调仅使用一台 GB200 NVL72 机架完成训练的效率。公告未提供独立的时延、质量或硬件需求测量数据。
