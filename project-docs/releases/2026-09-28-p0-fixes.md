## 修复

| 问题（基线证据） | 修复 |
| --- | --- |
| 线上 sitemap 大部分时间是仓库里提交的旧版：12 个网址、lastmod 2026-08-24。日报生成的 2562 个网址版本会被 Feed Collection 的「Event timeline」部署覆盖（gh-pages 上写入者在两者之间交替） | 删除 `docs/sitemap.xml` 并加入 `.gitignore`，只由日报生成；其他部署 `docs/` 的任务使用 `keep_files`，不再带旧文件。测试改为校验生成器输出，并新增「sitemap 不得被提交」回归测试 |
| 2026-09-25 语义去重收到只含 1 条的组（`group_too_short`），整期拒绝发布，08:44 才出刊 | 去重后不足 2 条的组（`[]`、`[3]`、`[3,3]`）不含任何合并决定，直接忽略；带合并意图但格式错误的（如 `[0,0,1]`）、越界、非整数仍按原规则失败关闭 |
| Google News 标题保留「- 媒体名」尾巴；21% 的链接是 `news.google.com` 跳转 | 抓取时去掉与 `<source>` 同名的尾巴；新式跳转令牌通过 Google 自身的两步请求解析为原文链接（每次最多 40 条、并发 4），任何失败保留原链接，成功的条目标记 `google_news_link_resolved` |
| PR135 的 CI 因 PyPI 503 失败 | pip-audit 仅在 ServiceError/连接错误/5xx 时重试（最多 3 次）；发现漏洞立即失败，不重试 |
| 聚合源噪音：一次采集 openPR 21 条、TechBullion 9 条；GDELT 两周入选 0 条 | 新增通用域名过滤（`allowed_domains`/`blocked_domains`）。Google News 屏蔽 8 个新闻稿/内容农场域名（按条目自带的发布方链接判断，在解析链接前过滤）；GDELT 改为 20 个主流财经/综合媒体白名单，`max_records` 35→100 |

## 验证

- `uv run pytest`：871 项通过（离线，无真实 AI、Google 或 X 调用；Google 解析用 MockTransport 覆盖成功、失败保留、关闭三种情况）。
- pip-audit 重试脚本用假 `uvx` 本地模拟：通过 / 发现漏洞（1 次即失败）/ 持续故障（3 次后失败）/ 一次故障后恢复（第 2 次通过）。
- `uv run python scripts/check_governance.py` 通过。
