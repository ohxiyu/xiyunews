# 2026-11-01 公开阅读路径 UI/UX 修复

任务：[Issue309](https://github.com/ohxiyu/xiyunews/issues/309)。当前会话为唯一编辑及生产整合负责人，分支 agent/reader-ux。用户明确要求自行排查、修改并部署，沿用检查通过、同步 main、PR 合并和正常自动发布流程。

## 已确认的问题与修复

正式域检查：首页重点追踪三条长进展先于当日日期和报道，手机首屏缺少当日内容；追踪筛选后点击其他分类的近期脉络会指向仍被隐藏的目标；追踪首卡使用固定 80px 锚点偏移，与手机实际页眉不符；详情重复显示日期且窄轨道挤占正文；折叠排行没有展开提示，部分按钮点击区域过小；历史加载成功后缺少定位与读屏反馈；排行滚动跟随调用 scrollIntoView 可能连带移动文档。

首页保留同一重点事件最近三条完整进展，增强后放在当日第一条报道后，先呈现日期、当日脉络和头条；无 JS 时三条仍完整保留在日期后。追踪首卡最多十条、其他最多三条、倒序与稳定链接不变。

分类隐藏的目标在锚点导航时恢复“全部”并同步筛选状态，折叠历史目标自动展开；页眉高度随实际布局测量，锚点偏移随之更新。排行跟随只滚动侧栏自身；j/k 尊重控件、弹窗、实际页眉与减少动态效果偏好。加载更早提供忙碌、成功/失败状态并定位首个新增刊期，失败保留重试。

详情保留机器可读完整时间与日期标题，辅助行只显示时刻及原始时区或历史刊期口径，避免重复日期；手机序号/日期横排、正文获得完整可用宽度，连接线与圆点独立。折叠标题增加加减提示，手机主要按钮与折叠入口最小 44px；背景实际未溢出时不显示多余展开按钮。

不改 AI、采集/出刊规则、来源、事件归属、原始目录与 API、Secrets、费用、DNS、Cron、实时服务或渠道发送状态，不重跑日报或补发历史，不手写产物分支。托管工作区创建工具未返回，改用已核对仓库中的普通独立 Git worktree；未碰其他会话的工作区。
