# 事件线质量

- Issue: [#142](https://github.com/ohxiyu/bmtnews-standalone/issues/142)
- Branch: `agent/event-quality`
- Scope: 事件目录中文字段回填与补译、事件页索引、日报事件标签。事件关系判定、时间线结构、API 字段不变。

## 基线

- 1179 个事件中 987 个中文标题是英文；追踪事件（≥2 次实质进展）115 个中 101 个是英文标题。
- 单条报道事件 1064 个（90%），各生成中英两页并进入 sitemap。
- 日报每条新闻都显示「事件记录」标签。

## 变更

| 项 | 内容 |
| --- | --- |
| 回填（无 AI） | `backfill_event_briefs` 在中文字段不含中文时，用已翻译条目/归档的 `title_zh` 替换标题；首条进展的「变化/现状」用中文详细摘要替换。已是中文的字段不改。事件标题取最早一条中文进展标题，现状取最新一条中文实质进展 |
| 补译（AI） | 采集时对追踪事件中仍是英文的标题/现状/进展说明批量翻译（新阶段 `event_translation`，关闭思考，每批≤12 段/3000 字符，每次最多 4 批）。译文必须含中文、长度不超过原文 2 倍 + 40、不得出现原文没有的数字（允许换单位），否则保留英文。没有新条目的采集也会推进积压 |
| 索引 | 单条报道事件页保留（日报与 API 仍链接），但加 `noindex`，并移出 sitemap |
| 日报标签 | 仅在事件有 ≥2 次实质进展时显示「持续追踪 · N 次进展」/「Tracking · N updates」 |

## 模拟与验证

- 生产事件目录 + 归档离线模拟：追踪事件英文标题 101 → 45（仅回填）；剩余 238 段、约 2.5 万字符待补译，约 2–3 次采集完成。
- `uv run pytest` 全部通过；新增 `tests/test_event_zh_quality.py`（回填不改写中文、非首条进展不整篇替换、只翻译追踪事件、译文校验、单条事件页 noindex、日报标签条件）。
- `uv run python scripts/check_governance.py` 通过。

## 尚未验证

- 已发布的单条事件页要等下一次重新生成才带上 `noindex`（事件页每次采集整体重写）。
