本文件只准备阶段 5 文案，尚未修改群、频道、机器人身份或推送代码。运营者确认措辞后再操作，日报频道与实时话题群仍是两个目标，群 ID、话题、权限和提醒规则不变；旧实时仓库不能在新仓部署验收前归档。

## 正文与运维提醒

当前 realtime 的行情/公告/资金流向发送正文没有 FomoBTC 品牌尾注，因此不为改名新增尾注或加长消息。日报的站点链接已统一为 xiyu.news，不重新发送历史内容。既有看门狗向运营者私聊的告警标题仍含 FomoBTC，是否同步改成“稀有News · 实时快讯”也在本次措辞确认范围内；修改后需要单独测试和已授权 Worker 部署，不把群名改动说成看门狗已发布。

## 执行与验收

1. 运营者确认上面的频道、群、简介及运维告警措辞，不用提供 Token、群管理密钥或验证码。
2. 运营者在 Telegram 分别修改既有频道与群的名称/简介，保留所有话题、成员权限和既有入口，不发送宣布改名的消息。
3. 如确认同步看门狗署名，用独立阶段 5 Issue/分支/PR 修改三个标题并运行既有 Node 回归；经授权部署原 Worker，不创建替代服务、不更换 Secrets 或清空 KV。
4. 从下一条自然消息核对目标话题与内容；不要制造告警、测试新闻或重发旧通知作为品牌验收。截图需要脱敏，不包含私聊接收者或账户资料。
5. 更新 [当前交接](handoff.md) 与真实发布记录，分别写明 Telegram 手工改名、代码测试、Worker 部署及自然回执，不把文案准备当作已上线。
