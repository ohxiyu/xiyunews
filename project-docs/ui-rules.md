# UI 规则

2026-11-09 用户提供的日报版重构方案优先。

- 主导航仅日报、往期、关于；保留原机器人Logo。英文生成、事件页面、排行、行情、编辑、纠错、Quick Post、PWA均停用。
- 首页展示最新一期完整日报，突出真实刊期、作者和本期更新时间。日报延迟时保留上一期日期，不把旧内容标为今天。
- 每条完整显示背景、正文和原始来源，顶部使用来源真实发布时间（日期、时分、时区）；历史缺失时间不补造。历史正文和锚点不改写。
- 密集阅读区最多1080px，浅灰/炭灰底、轻边框、品牌蓝；手机正文不额外缩窄。背景独立浅底区块完整呈现。
- 全文服务端静态渲染，无JS也可完整阅读；仅主题切换、复制链接、锚点和旧离线缓存清理需要JS。
- 底部提供关注@ohxiyu与真实Telegram入口。当前已核实入口为讨论群，文案不得冒称日报订阅频道；关于页说明作者、方法、时限与投资免责声明。
- 每页实际引用CSS+JS（包含内联脚本）不超过20,000字节，拒绝外部脚本或样式。不为性能预算删来源与版权。
- 核对桌面、320/390手机、暗色、键盘焦点、无JS、空状态、往期和锚点。测试构建与生产可达性分别核验。
- 独立realtime应用不受本站UI改版影响。
