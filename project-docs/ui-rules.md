# UI 规则

2026-11-08 用户批准的核心版规则优先于历史设计说明。

- 主导航仅日报、事件流、往期；英文代码保留，但不提供英文功能与切换入口。人工纠错、后台与 Quick Post 不上线。
- 首页只显示最新一期，以明确刊期日期区分当日与旧刊。移除大日期/窗口/采集统计和排行榜、行情、无限滚动。
- 前三条默认完整显示背景、正文和来源，顶部使用来源真实发布时间（日期、时分、时区）；不得使用采集/生成时间冒充新闻时间。
- 前三条后接最多三条实质事件进展，其他新闻使用原生 details/summary 折叠且全文仍在 DOM；无 JS 仍可完整阅读。
- 事件流按最新实质进展排序；首个事件显示全部不同进展，其他预览三条，详情完整。历史仅有刊期日期时明确标记，不补造小时分钟。
- 正文最多 740px，浅灰/炭灰背景、轻边框与品牌蓝；手机正文不额外缩窄。背景独立浅底区块完整呈现。
- 保留主题切换、复制链接和稳定锚点；去掉图片分享、书签/已读、PWA/离线。锚点目标自动展开并避让页眉。
- 核对桌面、手机、暗色、无 JS、键盘焦点、空状态、历史链接；发布前后有真实图片证据。功能测试不替代视觉验收。
- 保留版权、内容权利和来源说明。独立 realtime 服务不受本站 UI 改版影响。
