# UI 规则

适用于当前静态站点与分享卡片；修改先核对现有模板、CSS 和 [PWA 手册](pwa-reader.md)，不要按其他项目截图重设计。

- 主导航仅保留信息流、追踪和中英切换；实体入口归入追踪，周报停用，RSS 订阅保留但不在导航显示；来源管理不加入公开主导航，入口保持 /s。
- 首页默认两期；当前刊期和旧刊期必须可区分，不能把昨日排行冒充今日。
- 延续简洁紧凑排版。标题均衡换行，避免孤字；桌面正文限制阅读行宽，移动端不额外缩窄。
- 正文合理分段且完整呈现；背景、影响、来源与标签字号较小但可读，不靠两行截断隐藏主要内容。
- 移动和桌面均提供“分享”入口；面板含保存图片、复制图片及 X 分享。不得宣称 X intent 能自动附上本地图片。
- 分享图沿用手机阅读样式，只保留背景与完整正文、必要标题和品牌标识，排除交互按钮和浏览器浮层；不显示 localhost 链接。
- 响应式、暗色、中英长标题、空状态、加载失败、键盘/焦点均需按变更范围验收。UI PR 附变更前后图片和视口尺寸，功能测试不能代替视觉验收。
- 不凭空统一所有组件，尽量复用既有样式与渲染器；不改动与任务无关的菜单。

## 共享视觉层（2026-10-06）

- 公开页面采用已确认的 Beautiful UI 风格预览方向：浅灰/炭灰背景、轻边框面板、12px 面板圆角、8px 操作圆角、品牌蓝选中态；不复制组件库或增加框架、外部字体、AI 调用。
- 首页/日报、追踪与事件/实体详情、说明页通过 editorial-ui.css 共享令牌。内容、证据、菜单、默认两期、排行与折叠语义不变。
- 桌面正文 16px，手机保留 15px；分析 13px（手机 12.8px），正文宽度最多 740px，手机不额外限制。暗色与跟随系统模式同样使用共享令牌。
- 分享 PNG 从当前页面的 CSS 令牌读取配色，保持 440 CSS px / 3 倍导出与高度保护。背景在上、完整分段正文在下，不含分析、来源栏、参考、标签或评分；品牌只出现一次，没有交互按钮、页面 URL 或浏览器装饰。
- 独立后台 /s 的业务流程不在本次公开站点改版范围。

## 阅读辅助与重点追踪（2026-10-09）

- 首页/日报和事件卡采用“背景 → 完整报道/进展 → 影响分析与真实讨论 → 参考资料”的实际 DOM 阅读顺序。背景放在标题后，用浅底色、品牌蓝左边标识和明确标签区分，默认最多三行预览并可展开；正文/进展后的分析、参考和标签默认合并折叠，使用原生 details/summary，可点击或键盘展开，展开后保持明确标题与参考布局，不恢复混合标签页。影响分析不得标作社区讨论。正文与分享全文不截断，空字段不造占位，旧日报渐进增强与无 JS 新输出均保留完整内容。
- 追踪主列表最多六个合格重点事件，首个展示最近十条不同进展，其他展示三条，均提供证据入口。重点资格选择优先重要性、真实进展和未结束状态，以加密为主，不按转载量排名；选中事件按最近实质进展倒序展示，历史与原 URL 保留在折叠入口。
- 近期脉络三条和右侧重点导航引用同一重点集合。共享圆角、字号、配色、分类和收藏/已读操作，不增加逐条排行分割线或双重序号。
- 首页重点追踪保留重大、近期且持续发展的事件资格，展示该事件最近三条不同进展及各自稳定锚点，不截断主要事实。详情按发生时间倒序，同时间按首次发现时间与稳定 ID 决定顺序；不改写数据存储和公共 API 的历史顺序。
- 详情时间线使用统一面板，内部以轻分隔行和连续连接线呈现，不把每条进展嵌套为独立圆角卡片。序号、日期与圆点分栏，窄屏不重叠；来源依据和纠正标记保留，锚点目标有可见反馈，节点导航与正文顺序一致。

## 阅读路径细节（2026-11-01）

- 首页先呈现当日期刊与头条，再接同一事件的三条完整重点追踪，不截断事实；无 JS 时重点面板仍在日期之后完整保留。
- 分类筛选后，近期脉络或历史锚点必须能打开目标；目标被分类隐藏时恢复“全部”及其选中状态，折叠祖先自动展开。锚点避让实际页眉高度，排行跟随仅滚动侧栏自身。
- 手机主要分类、阅读动作及折叠入口至少 44px 高，桌面保留紧凑控件。折叠排行提供加减提示，短背景不显示无效展开按钮；历史加载明确展示忙碌/失败重试状态，成功后定位新增刊期并向读屏报告。
- 手机时间线序号与日期横排、圆点独立，不以窄日期列牺牲正文宽度；重复日期从辅助行移除，完整机器时间和原始时区/时间口径保留。
