# UI 规则

2026-11-08 用户批准的核心版规则优先于历史设计说明。

- 主导航仅信息流、事件流、往期；英文代码保留，但不提供英文功能与切换入口。人工纠错、后台与 Quick Post 不上线。
- 首页展示滚动最近24小时的合格精选，按来源发布时间倒序；紧凑工具栏展示真实采集/精选时间。无快照时明确标记归档兜底。保留原机器人Logo，移除大标题、排行榜、行情、无限滚动。
- 所有资讯默认完整显示背景、正文和来源，顶部使用来源真实发布时间（日期、时分、时区）；不得使用采集/生成时间冒充新闻时间。
- 滚动首页全文服务端渲染，无 JS 仍可完整阅读；稳定链接独立于窗口和排序，读取时移除过期资讯；刷新提示不打断阅读。归档首页兜底前三条后仍可预览事件进展。
- 事件流按最新实质进展排序；首个事件显示全部不同进展，其他预览三条，详情完整。历史仅有刊期日期时明确标记，不补造小时分钟。
- 密集版阅读区最多1080px，浅灰/炭灰背景、轻边框与品牌蓝；手机正文不额外缩窄。背景独立浅底区块完整呈现。
- 保留主题切换、复制链接和稳定锚点；去掉图片分享、书签/已读、PWA/离线。锚点目标自动展开并避让页眉。
- 核对桌面、手机、暗色、无 JS、键盘焦点、空状态、历史链接；发布前后有真实图片证据。功能测试不替代视觉验收。
- 保留版权、内容权利和来源说明。独立 realtime 服务不受本站 UI 改版影响。
