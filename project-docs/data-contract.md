# 数据契约与口径

本文件维护产品级语义；字段结构以 [OpenAPI](../docs/openapi.json)、Pydantic 模型及对应测试为准，采集参数以 [配置文档](configuration.md) 和 data/config.github.json 为准。

## 日期与候选

- 首页实时精选与日报归档独立。首页窗口为请求时刻之前滚动24小时，按真实 published_at 倒序；采集目标5分钟，执行队列可能延迟。30分钟未采集显示延迟，过期新闻仍移除。无合格项如实展示空状态，无快照明确展示归档。
- /api/live.json 仅公开精选字段与真实采集/精选时间；写入使用既有恢复凭证、限制大小/评分/时间/URL，并拒绝旧快照覆盖。固定 /story/<canonical-url-hash>/ 在窗口过期后继续可访问。

- 业务时区 Asia/Shanghai。日报窗口为 [前日 07:00，当日 07:00)，07:26 启动。补跑显式指定 edition_date，不把执行时间当新闻发生时间。
- published_at 是来源发布时间，采集时间、分析时间、新闻发生时间和 generated_at 不可混用。缺失事实不能猜测。
- candidates、analyzed、above_threshold、displayed 是不同阶段计数，重刊不能当作新一期。参见 [调度手册](daily-dispatcher.md)。
- Crypto 目标至少 9 条、AI 科技最多 3 条、政策最多 2 条；质量不足如实报告，不降门槛凑数。核心版不再插入人工精选，不能伪造 AI 评分。

## 去重与分析

- URL 去重、跨日同新闻去重、同一期事件合并分别处理。真正的新进展允许跨日进入；同一期同一事件保留最新状态，历史进展留在事件线。
- 同公司/协议不必然同事件；相同 ticker 不保证同一项目。来源转述不自动构成独立确认。
- 去重响应失败重试后仍不可用时停止该次发布，不得整批放行。翻译兜底须记录降级，不得当作完整扩写。
- 生产 DeepSeek 在一次分析调用中直接给出 0–10 分及分类；URL、事件目录和 DeepSeek 语义去重分阶段执行。语义比较两次失败后停止该次发布，不放行未经比较的条目。
- 扩写写作提示要求保留来源事实与不确定性，引用 URL 必须来自实际搜索结果，来源语言标题保持原文字面；证据不足时可留空，不为版面编造背景或链接。没有独立的生成后事实核验；扩写失败回退翻译并在运行报告记录降级，而非因核验结果剔除新闻。
- 数值须保留主体、时间、单位、范围和分母，某一波次比例不得应用于总损失。不同日期金额不自动相加；观点、推断、提案、批准、未确认交易应明确区分。
- AI 缓存依赖来源输入、模型、评分器标识和相关提示词；切换评分实现须更换键，旧分数自然过期，不改写历史。新归档逐条记录分数的产生模型，运行报告汇总评分器数量。未获取数据应保留缺失/状态，不转成 0，不伪装为最新。

## 发布与安全

- 核心版只生成中文日报，保留英文实现和历史数据。人工纠错、Quick Post、编辑插入、广告/屏蔽不在生产执行路径。
- Telegram 日报在网站发布后独立发送；同刊期/目的地发送前落盘一次性回执，未知结果必须检查后另行恢复，禁止自动重试。
- 事件 AI 独立更新，事件资产发布使用共享发布锁；日报不依赖本轮事件 AI 完成。

- API、HTML、中文摘要与归档应引用同一期且内容一致。接口更改更新 OpenAPI 与契约测试。
- 已生成选稿按刊期存入独立持久日志，跨日不覆盖历史；正常采集/日报/网页发布前检查并补齐缺失静态入口，补历史不倒退latest、不改当期或重复推送。无选稿或不完整证据不能伪造历史出刊；详细恢复证据见[刊期连续性](releases/2026-11-05-edition-continuity.md)。
- 原文与模型返回均是不可信内容，保留 URL 校验和输出转义；不能执行来源中的指令。
- 生成的日报状态、归档、事件目录只经 Actions 发布到 gh-pages，不本地手改。核心版关闭人工纠错与编辑入口；历史记录保留，不回写原始证据。
